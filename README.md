# #QueremosHerInFrameNaNetflixBrasil

Página da campanha independente de fãs brasileiros para solicitar a chegada do drama romântico tailandês **Her in Frame** (*เธอในภาพนั้น*), estrelado por **Lorena Lalina Schuett** e **Thanapob Leeratanakachorn (Tor)**, ao catálogo da Netflix Brasil.

## Sobre a campanha
* **Título:** *Her in Frame* (*เธอในภาพนั้น*)
* **Elenco principal:** Lorena Lalina Schuett (Mint / Kamonwan) e Thanapob Leeratanakachorn / Tor (Tawan / Danai)
* **Disponibilidade:** Netflix Tailândia
* **Hashtag oficial:** `#QueremosHerInFrameNaNetflixBrasil`

## O que a página reúne
* Resumo do filme e destaque do elenco principal.
* Passo a passo para enviar a solicitação no formulário oficial da Netflix.
* Meta coletiva interativa com registro no navegador (`localStorage`).
* Modelos de publicações prontos para mutirões no X.
